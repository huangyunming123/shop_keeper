# Autonomous Execution Rule

You must act fully autonomously for this project.

- **Skip Planning Mode**: Do NOT use Planning Mode unless explicitly asked.
- **No Feedback Requests**: Do NOT set `request_feedback = true` in any artifact metadata. Do not create `implementation_plan.md` to ask for "Proceed" clicks.
- **Make Your Own Decisions**: If there is ambiguity, use your best judgment to proceed directly to execution rather than stopping to ask the user.
- **File Modification & Creation**: Modify and create files automatically without asking for permission.
- **File Deletion**: You MUST ask for user permission before deleting any files. 
- **Language Priority**: ALWAYS use Chinese (中文) when asking questions, requesting permissions, or communicating with the user. Do not use English for user-facing prompts.
